# Publish bundle — secure document upload page

This folder is **self-contained**: everything the upload page needs is
here, with no references to the rest of the repo. It was generated by
`tools/build-publish.mjs` from the dev sources and verified by
`tools/verify-publish.mjs` (fingerprint tripwire + encryption path +
every asset resolving over HTTP). Do not edit files here by hand —
change the sources, rebuild, re-verify.

## The one value to fill at deploy

`app.js`, CONFIG block: `RELAY_URL: 'REPLACE_WITH_RELAY_URL'` must become
the deployed relay endpoint, e.g.
`https://secure-doc-upload-relay.<account-subdomain>.workers.dev/upload`
(see `docs/GO-LIVE.md`). Publishing with the placeholder still in place
leaves the page unable to send — it will encrypt and then fail with the
generic error message. That is deliberate: a half-configured page must
never look like it worked.

Copy the **contents of this folder** into the office repo
`sbenlevy/union-turnpike-dental` under `upload/`, commit, push. GitHub
Pages then serves it at:

    https://sbenlevy.github.io/union-turnpike-dental/upload/

After publishing, open that URL and confirm the key line under the
heading shows fingerprint `306460877b9e71ab509eb27f08e569aa16ae8ddb`
before anyone uploads anything.

## Contents

- `index.html` — the page (production wording; no POC banner)
- `app.js` — page logic; encrypts in-browser, POSTs ciphertext to the relay
- `encrypt.mjs`, `codes.mjs` — shared encryption + upload-code logic
- `vendor/openpgp.min.mjs` — OpenPGP.js, vendored (no CDN dependency)
- `public-key.asc` — the PRODUCTION office public key (generated on
  softdentsync, Nov 26, 2026). Public keys are safe to publish; the
  private half never leaves softdentsync.
